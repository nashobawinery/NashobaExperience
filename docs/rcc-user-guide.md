# Nashoba Revenue Command Center (RCC)

## User Guide

### What This Module Is

The Revenue Command Center is Nashoba Valley's weekly operating system for driving revenue. It helps us:

- Set one clear weekly focus ("what matters this week")
- Assign tasks with owners and due dates
- Track campaigns (website/email/social/on-site)
- Log results (Toast + Shopify revenue)
- Capture learnings (what worked / what didn't)
- Stay organized without losing momentum

---

## The Weekly Rhythm

Every week follows the same loop:

| Day | Activity |
|-----|----------|
| Monday | Plan the week |
| Tuesday-Sunday | Execute tasks & campaigns |
| Daily or End of Week | Log revenue + notes |
| Friday-Sunday | Record learnings |
| Next Monday | Review results and adjust |

---

## Roles and Responsibilities

### Owner / Admin
- Creates each week
- Assigns the weekly theme/hook/goal
- Assigns owners to tasks and campaigns
- Reviews revenue & learnings

### Managers
- Own tasks in their department (Retail, Restaurant, Events, etc.)
- Update status and add comments
- Add learnings and feedback

### Staff
- Complete assigned tasks
- Mark progress and add brief comments
- Add customer feedback learnings when relevant

## 1. Weekly Dashboard

### Purpose

The Weekly Dashboard is the "home base" for the current week. It answers:

- What are we focusing on this week?
- What's the main reason customers should visit now?
- What's the goal?
- What tasks and campaigns must happen?

### Key Fields

| Field | Description | Example |
|-------|-------------|---------|
| **Theme** | Short name for the week | "Weekend Recovery Push" |
| **Primary Hook** | The "why now" headline | "This Weekend: Tastings + Farm-to-Table + Live Music" |
| **Primary Goal** | Measurable outcome | "Increase on-property traffic and tasting room revenue vs last week" |
| **Status** | Week lifecycle | planned → active → complete |

### How to Use It

1. Review the hook and goal at the start of the week
2. Use the Dashboard to quickly jump to tasks, campaigns, and revenue entry
3. Keep the hook consistent across channels

---

## 2. Tasks

### Purpose

Tasks are the execution engine. Every task should have:

- A clear title
- An owner
- A due date
- A status

### Common Task Types

| Type | Example |
|------|---------|
| Website updates | "Add 'This Weekend' banner" |
| Email preparation | "Draft and send Weekend Email" |
| Social posting | "Schedule 3 posts for weekend traffic" |
| On-site execution | "Train staff to ask for emails at checkout" |

### Task Statuses

| Status | Meaning |
|--------|---------|
| **To Do** | Not started |
| **Doing** | Actively in progress |
| **Blocked** | Can't proceed (needs input/approval) |
| **Done** | Completed |

### Best Practices

- Keep tasks small (1-2 hours of work when possible)
- Use "Blocked" early (don't let tasks silently stall)
- Add comments when something changes or needs review

## 3. Campaigns

### Purpose

Campaigns track the messages we send out to generate business.

A campaign can be:
- Email
- Website message
- Social push
- On-site signage or staff script
- Ads (if used)

### Campaign Statuses

| Status | Meaning |
|--------|---------|
| **Draft** | Being written |
| **Scheduled** | Assigned a date/time to go out |
| **Sent** | Executed |
| **Cancelled** | Intentionally not used |

### Key Fields

| Field | Description |
|-------|-------------|
| **Channel** | Where it runs (email / website / social / onsite / etc.) |
| **Audience** | Who it targets (simple description) |
| **Offer** | Optional ("no offer", "10% tasting", "limited release") |
| **Message Subject/Body** | The actual copy (if relevant) |
| **CTA URL** | Where customers should click/go |

### How to Use It

1. Create a campaign when you know a message is going out
2. Put the copy in the campaign record so it's searchable later
3. After sending, update status to "Sent" and record basic results (if available)

## 4. Revenue Entry (Toast + Shopify)

### Purpose

Revenue entry provides the "scoreboard." It lets us compare weeks and learn what moves revenue.

### What to Enter

For each day (or at least weekly totals), enter:

| Field | Description |
|-------|-------------|
| **Source** | Toast or Shopify |
| **Location** | Overall or specific department (tasting_room / restaurant / retail / events) |
| **Gross sales** | Total before adjustments |
| **Net sales** | After discounts/refunds |
| **Transactions** | Number of orders |
| **Guests** | If you track it |
| **Notes** | Optional but helpful |

### Minimum Required for MVP

If you want the simplest approach:
- Enter daily totals for Toast overall
- Enter daily totals for Shopify overall

That's enough to see trends.

### Best Practices

- **Consistency beats perfection**: enter numbers the same way every time
- **Use Notes to flag anomalies**: snowstorm, private party, major event

## 5. Learnings (Wins / Losses / Ideas / Feedback)

### Purpose

Learnings are how we avoid repeating mistakes and scale what works.

This is where you capture:

| Type | Description |
|------|-------------|
| **Wins** | What worked and should be repeated |
| **Losses** | What flopped or created friction |
| **Ideas** | Future tests |
| **Customer Feedback** | What guests said (good or bad) |

### How to Write a Good Learning

**Win:**
> "'This Weekend' homepage banner increased calls about reservations."

**Loss:**
> "Email went out too late Friday; weekend traffic bump was minimal."

**Customer Feedback:**
> "Multiple guests asked if tastings require reservations."

**Idea:**
> "Test 'Rainy Day Indoor Tastings' message when forecast is wet."

### Field Guidance

| Field | Required? |
|-------|-----------|
| **Observation** | Required - what happened |
| **Next Action** | Recommended - what we'll do next time |

## Weekly Operating Procedure

### Monday (Planning)

- [ ] Create or open the week
- [ ] Confirm Theme / Hook / Goal
- [ ] Add 3-7 tasks and assign owners
- [ ] Create 1-3 campaigns (even as drafts)

### Midweek (Execution)

- [ ] Owners update task statuses
- [ ] Draft/schedule campaigns
- [ ] Add comments to unblock issues quickly

### Friday-Sunday (Results + Learnings)

- [ ] Enter revenue totals (or confirm they're entered)
- [ ] Add at least 3 Learnings:
  - 1 win
  - 1 loss
  - 1 customer feedback or idea

### Next Monday (Review)

- [ ] Mark last week complete
- [ ] Review learnings and revenue
- [ ] Choose the next weekly hook

## Tips for Success

> These are what make RCC work

1. **Keep the weekly hook simple and consistent**
2. **Assign fewer tasks, but finish them**
3. **Track campaigns even if results are "unknown"** (you'll improve over time)
4. **Treat Learnings as mandatory** - they're what makes the system smarter

## Troubleshooting

### "I'm not sure what to do this week."

Go to the **Weekly Dashboard** and read:
- **Primary Hook** (what we're pushing)
- **Primary Goal** (what we need to move)

Then check **Tasks** for your assignments.

### "A task is blocked."

Set status to **Blocked** and add a comment with what you need:
- Approval
- Copy
- Image
- Decision

### "We didn't send a campaign."

Set campaign status to **Cancelled** and add a note why. This helps future planning.

### "Revenue looks wrong."

Check:
- Date entered correctly
- Source (Toast vs Shopify)
- Location (overall vs department)

Add a note explaining any mismatch.
