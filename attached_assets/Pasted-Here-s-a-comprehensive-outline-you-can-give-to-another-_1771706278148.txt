Here's a comprehensive outline you can give to another Replit agent to build a similar digital signage/TV station system for Nashoba Valley Winery:

Project: Nashoba Valley Winery - Digital Signage & TV Display System

Overview:
Build a web-based digital signage system ("NashobaTV") for Nashoba Valley Winery that displays rotating content on smart TVs, Fire Sticks, or any device with a browser. The system should include an admin panel for content management and a public-facing auto-rotating display.

Core Architecture:

Full-stack TypeScript application (React frontend, Express backend, PostgreSQL database)
Two main interfaces: (1) Admin dashboard for managing content, (2) Public display page that auto-rotates through slides
The public display page should run at a URL like /display with no authentication required
Admin panel should be behind authentication with role-based access
Display System - Auto-Rotating Slides:

The public display (/display) should cycle through different slide types automatically. Each slide type has its own duration and visual design. Suggested slide types for a winery:

Welcome/Branding Slide - Winery logo, tagline, hours of operation (10-15 second duration)
Today's Events - Live music, tastings, tours, private events happening today (12 seconds)
Wine Menu / Tasting List - Current wines available for tasting with descriptions and prices (15 seconds)
Food Menu - Restaurant/cafe menu items, seasonal specials (15 seconds)
Upcoming Events Calendar - Next 7-14 days of scheduled events (12 seconds)
Photo Gallery - Rotating vineyard/winery photos, event photos (8 seconds per photo)
Announcements - Special promotions, seasonal announcements, wine club info (10 seconds)
Weather Widget - Current conditions relevant to outdoor seating/vineyard tours (8 seconds)
Wine Club Promotion - Benefits, sign-up info, member specials (10 seconds)
Daily Specials / Happy Hour - Time-specific food and drink deals (10 seconds)
Display Technical Requirements:

Full-screen, no scrollbars, no browser chrome visible
Smooth fade or slide transitions between content
Auto-advances through all enabled slide types in a continuous loop
Each slide type can be individually enabled/disabled from admin
Background images configurable per slide type (stored in object storage or database)
Clock/date display in a corner
Responsive design that works on various TV resolutions (1080p, 4K)
No user interaction needed - purely passive display
Should gracefully handle missing data (skip slides with no content)
Admin Panel Features:

Event Management

Create/edit/delete events with title, description, date, time, location (indoor/outdoor), category (music, tasting, tour, private)
Recurring event support
Event status (upcoming, active, completed, cancelled)
Calendar view and list view
Wine Menu Management

Add/edit wines with: name, varietal, vintage year, description, tasting notes, price per glass, price per bottle, availability status
Categories: Red, White, Rosé, Sparkling, Dessert, Seasonal
Mark wines as "featured" or "new arrival"
Tasting flight builder - group wines into themed flights
Food Menu Management

Menu items with name, description, price, category
Categories: Appetizers, Entrees, Desserts, Cheese Boards, Seasonal Specials
Ability to mark items as daily specials
Allergen/dietary tags (GF, vegan, etc.)
Announcements & Promotions

Create announcements with title, body text, start/end display dates
Priority ordering
Auto-expire based on end date
Photo Gallery Manager

Upload photos with captions and categories
Categories: Vineyard, Events, Food & Wine, Seasonal, Facility
Enable/disable individual photos from display rotation
Sort order control
Display Settings

Enable/disable each slide type
Set duration per slide type
Set display order
Background image management per slide type
Preview mode to see what the TV display looks like
Wine Club Management (optional)

Member benefits list
Current promotions for display
Database Schema (Key Tables):

events - id, title, description, date, startTime, endTime, location, category, isRecurring, status, imageUrl
wines - id, name, varietal, vintage, description, tastingNotes, priceGlass, priceBottle, category, isFeatured, isAvailable, sortOrder
menu_items - id, name, description, price, category, isDailySpecial, dietaryTags (JSONB array), isAvailable
announcements - id, title, body, startDate, endDate, priority, isActive
photos - id, url, caption, category, isDisplayed, sortOrder
display_settings - id, slideType, isEnabled, duration, sortOrder, backgroundImageUrl
tasting_flights - id, name, description, price, wineIds (JSONB array)
daily_specials - id, title, description, validDate, happyHourStart, happyHourEnd
Public API Endpoints (no auth required, for display page):

GET /api/public/display/events/today - Today's events
GET /api/public/display/wines - Available wines
GET /api/public/display/menu - Current food menu
GET /api/public/display/announcements - Active announcements
GET /api/public/display/photos - Enabled gallery photos
GET /api/public/display/settings - Display configuration
GET /api/public/display/specials - Daily specials and happy hour
Visual Design Guidance:

Winery/vineyard aesthetic: warm earth tones, deep burgundy/wine red accents, cream/ivory backgrounds
Elegant serif fonts for headings (like Playfair Display), clean sans-serif for body text
Dark backgrounds work well for TV displays (easier on eyes, better contrast)
Large text - viewers may be 10-30 feet from the screen
Minimum font size should be equivalent to ~24px at 1080p
High contrast between text and backgrounds
Use semi-transparent overlays on photo backgrounds to ensure text readability
Subtle animations (fade-ins, gentle slides) - nothing jarring or distracting
Deployment Notes:

The /display page should be accessible without login - this is what runs on the TVs
On a Fire Stick or smart TV, open the browser and navigate to [app-url]/display
The TV browser should be set to full-screen/kiosk mode
The display page should auto-refresh data periodically (every 2-5 minutes) without reloading the page
Consider adding a simple URL parameter for different display locations (e.g., /display?location=tasting-room vs /display?location=patio)
This outline covers the core structure. The agent should prioritize getting the auto-rotating display working first, then build out the admin management features one module at a time. Start with events and wine menu since those are the most essential for a winery.
