📊 Back Office Inventory Report — Specification
1. Purpose

Provide a consolidated, spreadsheet-style report showing all inventory counts taken on a given date. The report enables management to review:

Total inventory counted across the entire Location

Per-area quantities

Alphabetical product list

Export capability (CSV, Excel)

2. Report Selection Controls

At the top of the report page:

Filters

Date (single date selector)

Location (dropdown; default = All or Last Used Location)

Export Buttons

Export to CSV

Export to XLSX

Behavior

When a user selects a date, the system should:

Find all inventory_sessions whose completed_at matches that date.

Filter sessions by selected location.

Aggregate counts for each product across:

All areas

Each individual area

3. Data Logic (Backend Requirements)
3.1 Determine included areas

For the selected location:

Gather all areas

Filter for areas that had an inventory session on the chosen date

3.2 Build product list

Start with the products table

Only include products that appear in any inventory count for that date

Sort alphabetically by product name

3.3 Build totals

For each product:

Total Count Across Location (Date-Specific)
SUM of all inventory_counts.quantity 
WHERE inventory_counts.product_id = X
AND session.completed_at = selected_date
AND session.area_id belongs to selected_location

Per-Area Count

For each area:

SUM of inventory_counts.quantity 
WHERE inventory_counts.product_id = X
AND session.area_id = this_area
AND session.completed_at = selected_date

4. Spreadsheet Layout (Front-End Display)

The grid should look like this:

Header Row Example
Product	Total	Area A	Area B	Area C	Area D	…
Chardonnay 2020	145	72	18	55	0	…
Fruit Wine Mix Pack	64	12	4	48	0	…
Maple Syrup 375ml	21	3	7	11	0	…
…	…	…	…	…	…	…
Notes:

Product Column = Product Name (alphabetized)

Total Column = Sum of all areas for that day

Each remaining column = One area in the location

Areas appear in alphabetical order or user-defined sort order

5. Edge Cases
Multiple Physical Counts for Same Area Same Day

If an area is counted twice on the same date:

Option A (default): Sum them together

Option B (optional feature): Let admins toggle:

“Use last count only”

“Sum all counts”

“Flag duplicate counts”

Products Not Counted in an Area

Display “0” rather than a blank cell.

Areas with No Counts on Selected Date

Hide area column, or gray it out
(Use system setting: “Hide empty areas”)

6. Export Requirements
CSV & Excel (XLSX)

Export should match the exact grid:

First row: Location name + "Inventory Summary — {date}"

Second row: Column headers

Subsequent rows: Product → totals → per-area counts

Optional:

Hidden metadata sheet:

Location ID

Area IDs

Date generated

User who exported
