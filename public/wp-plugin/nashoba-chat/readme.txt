AI-powered customer support chat widget for Nashoba Valley Winery.

== Description ==

Add an AI-powered chat widget to your WordPress site that answers customer questions using your Nashoba Valley knowledge base.

Features:
* Floating chat button with customizable position
* AI-powered responses from your knowledge base
* Configurable colors, size, and placement
* Mobile responsive
* Shortcode support for inline embedding
* Exclude specific pages

== Installation ==

1. Download the plugin ZIP file
2. Go to WordPress Admin > Plugins > Add New > Upload Plugin
3. Upload the ZIP file and click Install Now
4. Activate the plugin
5. Go to Settings > Nashoba Chat to configure

== Configuration ==

After activation, go to **Settings > Nashoba Chat** to:

* Enable/disable the widget
* Set the API URL (default: https://nashobawinery.org)
* Choose position (bottom-right, bottom-left, top-right, top-left)
* Adjust offset from screen edges
* Set widget width and height
* Customize button colors (gradient)
* Change header text
* Enable/disable on mobile
* Exclude specific pages

== Shortcode ==

Embed the chat inline on any page or post:

`[nashoba_chat]`

With custom dimensions:

`[nashoba_chat width="400" height="500"]`
